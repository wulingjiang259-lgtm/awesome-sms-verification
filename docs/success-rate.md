# 收码成功率优化

## 影响成功率的五个因素

1. **号码类型**：实卡 > 虚拟号池 > VoIP > 公共免费号。
2. **号段热度**：被大量注册过的号段容易被目标平台拉黑，换号段通常能解决。
3. **网络环境**：号码地区与访问 IP 地区不一致会显著降低通过率。
4. **账号历史**：同一设备/账号反复触发验证会被风控。
5. **时效**：号码过期后无法接收短信，二次验证直接失败。

## 操作清单

- [ ] 目标平台风控严格（Google、OpenAI、银行）时只选实卡号段
- [ ] 号码地区与网络节点保持一致
- [ ] 一个号码只注册一个账号
- [ ] 收不到码：先同步最新短信 → 再换号段 → 最后找客服
- [ ] 重要账号选 21-30 天档位，并在到期前续费
- [ ] 批量场景记录号码与账号的对应关系
