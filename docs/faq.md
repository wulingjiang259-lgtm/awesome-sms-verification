# 常见问题

**Q：接码和虚拟号是一回事吗？**
A：不是。接码是「接收验证码」的统称，号码可以是实卡、虚拟号或公共号；成功率差异很大。

**Q：为什么一定要实卡？**
A：Google Voice、OpenAI、银行类平台能识别 VoIP 与公共号池并直接拒绝，实卡兼容性最好。

**Q：号码能用多久？**
A：按档位计（2-10 天、11-20 天、21-30 天），到期可续费，每次 30 天。

**Q：收不到短信怎么办？**
A：先同步最新短信，再换号段重试；仍失败联系客服。

**Q：支持批量吗？**
A：支持多号段批量下单、整批导出 txt，以及 API 程序化取码。

**Q：可以给自己的站做上游吗？**
A：可以，用 API 对接，对外域名可隐藏上游。
